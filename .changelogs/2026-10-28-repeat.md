# 2026-10-28 — `--repeat`: thresholds on the median, instability made visible

**Type**: feature

**Summary**: The seed fixes the gremlins, not the model, so one LLM run per scenario made thresholds flaky. `--repeat N` (or `repeat:` per scenario) runs a scenario N times with the same seed; the median run is the scenario's report and its thresholds, a leak in any run fails it, and `thresholds.stability_spread` flags a scenario whose scores spread too far.

**Impact**:
- Core (`pkg/…`): none
- Arena (`internal/arena/…`): none
- CLI / plugin / Action: `arena ci --repeat`, `--strict-stability`, a cost line before the run (stdout, or stderr with `--format json`); the text output shows each run and the spread; the PR comment shows "median of 3, 55–62" and "⚠️ unstable", and counts leaks of every run. The Action reads `repeat:` from the config
- Formats: `scenarios[].repeat`, `thresholds.stability_spread` in `.gremlyn/arena.yaml`; `runs[]`, `stats`, `unstable` in the report, absent with one run
- Score comparability: unchanged for one run. With repeats, a scenario's score is its median run

**For users**: `gremlyn arena ci --repeat 3`. It costs three times as many agent launches.

**For developers**: `aggregateRuns` is pure and holds the rules; `runRepeated` only runs.
